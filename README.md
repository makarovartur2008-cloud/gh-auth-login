# 🥔 Картошка: заказы, клиенты, деньги

Telegram-бот и приложение внутри Telegram для доставки овощей. Работает на Android и iPhone, ставить ничего не нужно.

## Что умеет

- **Голосом или текстом**: «Марина, Ленина 5, подъезд 2, этаж 4, два мешка белой на завтра». Бот сам создаёт клиента и заказ, ты подтверждаешь кнопкой.
- **Деньги голосом**: «Отвёз Ивану мешок картошки и 10 кг лука, заплатил 2000 переводом», «Заправился на 3000».
- **Скриншоты и тексты с Авито**: друг пересылает переписку в бота, и получается заявка. Тебе приходит уведомление.
- **Каждое утро (8:00)** приходит список доставок на сегодня с адресами, телефонами, суммой и тем, что грузить в машину. **Вечером (20:00)** приходит список на завтра.
- **Постоянные клиенты** (каждые 7, 14 или N дней): заказ ставится в список сам, никто не забудется.
- Кнопки у заказа: **✅ Наличка / ✅ Перевод / 📝 В долг / ➡️ На завтра / ❌ Отмена**.
- **Приложение** (кнопка «📱 Приложение» в боте):
  - заказы на любой день;
  - база клиентов с историей;
  - цены;
  - расходы, долги, прибыль за день, неделю и месяц.

### Как считается прибыль

```
Прибыль = выручка − закупочная цена проданного − 50 ₽ другу за каждую его заявку − расходы (газ, прочее)
```

- Закупочная цена берётся из вкладки «Цены» (картошка 20 ₽/кг, лук 20, морковь 27, свёкла 22).
- Закупку партии товара можно записать («купил картошки на 20 000»). Она видна отдельно и в прибыль второй раз не вычитается.
- Заявки, которые создаёт друг, автоматически помечаются «через друга» (−50 ₽). Отметку можно снять в заказе.

## Запуск (один раз, примерно 20 минут)

### 1. Создать бота
1. В Telegram открой **@BotFather** → `/newbot`.
2. Придумай имя (например «Картошка Артура») и username, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `123456:ABC...`. Сохрани его.

### 2. Ключ для распознавания голоса
1. Зарегистрируйся на **proxyapi.ru** (оплата в рублях).
2. Пополни баланс на 200–300 ₽. Этого хватит надолго: голосовое стоит копейки.
3. В личном кабинете создай **API-ключ** и сохрани его.

> Без ключа бот и приложение работают, только голосовые и скриншоты не распознаются. Заказы тогда добавляются через приложение.

### 3. Сервер (~200–400 ₽/мес)
1. Купи самый дешёвый VPS с **Ubuntu 24.04** (1 CPU, 1 ГБ RAM), например на Timeweb Cloud, Beget или Aeza.
2. Запиши **IP-адрес** и **пароль root**.
3. Подключись к серверу:
   - с Android через приложение **Termux**: `ssh root@IP`;
   - или через **JuiceSSH**.
4. Выполни команды:
   ```bash
   git clone https://github.com/makarovartur2008-cloud/gh-auth-login.git kartoshka
   cd kartoshka
   bash deploy.sh
   ```
5. Скрипт спросит токен бота и ключ ИИ, потом сам всё установит. Домен и https настраиваются автоматически через `ВАШ-IP.sslip.io`, покупать домен не нужно.

### 4. Начать работу
1. Открой своего бота и нажми **Start**. **Первый, кто нажал, становится владельцем.** Поэтому нажми сам, сразу после запуска.
2. Команда `/invite` даёт одноразовую ссылку для друга.
3. Открой **📱 Приложение → Цены** и проставь цены продажи лука, моркови, свёклы и закупку мёда.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | подсказка и кнопки |
| `/invite` | ссылка-приглашение для друга (только владелец) |
| `/users` | кто имеет доступ |
| `/remove ID` | убрать доступ |

## Обслуживание

- **Обновить** после новых изменений: `cd kartoshka && git pull && docker compose up -d --build`
- **Резервная копия базы**: `bash backup.sh` (хранятся последние 30 копий). Чтобы делать копию автоматически каждую ночь:
  `(crontab -l; echo "0 3 * * * cd /root/kartoshka && bash backup.sh") | crontab -`
- **Логи**: `docker compose logs -f app`
- Все данные лежат в одном файле: `data/app.db`.

## Для разработки

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest
DEV_USER_TG_ID=1 uvicorn app.main:app --reload   # приложение без Telegram (нужен пользователь с tg_id=1 в базе)
```

Устройство проекта:
- `app/bot.py`: Telegram-бот (aiogram);
- `app/api.py`: API для приложения (FastAPI);
- `app/ai.py`: распознавание голоса и разбор фраз;
- `app/services.py`: логика заказов, постоянных клиентов и прибыли;
- `app/db.py`: база SQLite;
- `app/static/`: интерфейс приложения.
