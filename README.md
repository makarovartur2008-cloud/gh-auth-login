# 🥔 Картошка: заказы, клиенты, деньги

Telegram-бот и приложение внутри Telegram для доставки овощей. Работает на Android и iPhone, ставить ничего не нужно.

## Что умеет

- **Голосом или текстом**: «Марина, Ленина 5, подъезд 2, этаж 4, два мешка белой на завтра». Бот сам создаёт клиента и заказ, ты подтверждаешь кнопкой.
- **Деньги голосом**: «Отвёз Ивану мешок картошки и 10 кг лука, заплатил 2000 переводом», «Заправился на 3000».
- **Скриншоты и тексты с Авито**: друг пересылает переписку в бота, и получается заявка. Тебе приходит уведомление.
- **Каждое утро (8:00)** приходит список доставок на сегодня с адресами, телефонами, суммой и тем, что грузить в машину. **Вечером (20:00)** приходит список на завтра.
- **Постоянные клиенты** (каждые 7, 14 или N дней): заказ ставится в список сам, никто не забудется.
- Кнопки у заказа: **✅ Наличка / ✅ Перевод / 📝 В долг / ➡️ На завтра / ❌ Отмена**.
- **Приложение** (кнопка «📱 Приложение» в боте):
  - заказы на любой день;
  - база клиентов с историей;
  - цены;
  - расходы, долги, прибыль за день, неделю и месяц.

### Заказ по QR-коду (для клиентов)

- Страница `https://ВАШ-АДРЕС/order` — клиент без Telegram выбирает товары (картошка сетками от 25 кг, овощи от 5 кг, мытая морковь от 20 кг), день доставки на 2 недели вперёд, вводит адрес и телефон. Товары — плитками с фото, у картошки цена за сетку.
- **Фото товаров:** 📱 Приложение → «Цены» → нажми на товар → «📷 Добавить фото» (можно сразу с камеры). Фото ужимается на телефоне и хранится рядом с базой.
- Заявка сразу приходит в бот тебе и другу с кнопками «Доставлено / В долг / Отмена» и попадает в список заказов. Клиент сам добавляется в базу (если он уже есть — его данные не перетираются).
- **Листовки:** 📱 Приложение → «Цены» → «🖨 Листовки с QR». Впиши метку (например «Ленина 5») → откроется лист A4 с двумя листовками A5 → «Печать» или «Сохранить PDF», распечатай и разрежь.
- Для каждого дома делай свою метку: в «Финансах» видно, сколько заказов и денег принесла каждая листовка.
- **Отзывы:** QR на обороте визитки ведёт на `https://ВАШ-АДРЕС/otzyv` — клиент ставит оценку и пишет пару слов, отзыв приходит в бот с напоминанием про подарок (по умолчанию «5 кг моркови», переменная `REVIEW_GIFT`). Когда появится карточка в Яндекс Картах или 2ГИС, впиши ссылку на отзывы в переменную `REVIEW_URL` — `/otzyv` начнёт вести туда, визитки перепечатывать не нужно.
- **Отзыв на Авито:** впиши ссылку на свой профиль Авито в переменную `AVITO_URL` — на странице отзыва первой будет кнопка «⭐ Отзыв на Авито», а форма ниже нужна, чтобы знать, кому подарок (текст там необязателен).
- **Вкладка «Отзывы» на сайте:** под каждым отзывом в боте есть кнопка «👁 Показать на сайте» — показываются только отобранные тобой отзывы (имя без фамилии, без телефона).
- Там же кнопка «📋 Ссылка для Авито» — вставь её в объявление.
- Защита от спама: не больше 5 заявок в час с одного устройства.

> ⚠️ QR-код содержит адрес сервера. Адрес вида `1-2-3-4.sslip.io` привязан к IP: если сменишь сервер, напечатанные коды перестанут работать. Перед большой печатью лучше купить домен (`.ru` ~200 ₽/год), прописать его в `.env` (`DOMAIN` и `WEBAPP_URL`) и выполнить `docker compose up -d`.
>
> Клеить объявления на подъезды без согласия управляющей компании во многих городах запрещено (штраф) — договорись с УК/старшим по дому или используй доски объявлений.

### Сообщения клиентам

Клиенту приходит «Заказ №N принят! Привезём завтра…», вечером накануне — «Завтра привезём ваш заказ, примерно 14:00–15:00», а по кнопке «🚚 Еду» — «Выехал к вам, буду минут через 15–30».

Как это работает:
- **Telegram и MAX (бесплатно).** Бот может написать человеку, только если тот сам открыл бота. Поэтому после заказа на странице `/order` клиент видит кнопки «Получать статус заказа в Telegram / в MAX». Нажал → бот ответил «Вы подписаны на заказ №…» и сразу прислал статус. Клиент в Telegram — это тот же бот, но доступа к заказам и меню у него нет, владельцем он стать не может. На вопросы бот отвечает «По вопросам звоните …».
- **SMS (платно, по желанию).** Если задан `SMS_RU_API_ID`, SMS уходит при заказе с сайта и вечером со временем доставки. Несколько рублей за SMS — проверь тариф на sms.ru. Текст короткий, укладывается в 1 SMS.
- **WhatsApp — только вручную.** Бесплатного и безопасного способа писать в WhatsApp из программы нет: официальный API требует проверку бизнеса в Meta и оплату, а неофициальные библиотеки приводят к блокировке номера. Поэтому у карточки заказа есть кнопка **💬 WhatsApp**: она открывает чат с клиентом с уже готовым текстом (дата и время) — остаётся нажать «Отправить».

Когда что отправляется:
- заявка с сайта → «принят» (обычно доходит SMS, остальное — когда клиент подпишется);
- заказ, который внесли вы сами, клиенту автоматически **не** пишется. У карточки заказа есть кнопки **📣 Сообщить клиенту** (статус и время, если уже известно) и **🚚 Еду**. Если клиент нигде не подписан, бот подскажет нажать WhatsApp;
- каждый вечер в `EVENING_HOUR`:05 (по умолчанию 20:05) считается маршрут на завтра, и каждому подписанному клиенту уходит примерное время (один раз на заказ; при переносе заказа — снова).

Бот в MAX (по желанию):
1. Зайди на **business.max.ru** (нужен статус самозанятого/ИП/организации) → «Чат-боты» → создай бота.
2. В настройках бота (⋮ → Настройки) скопируй **токен** и впиши в `.env`: `MAX_BOT_TOKEN=...`.
3. `docker compose up -d`. Приложение само опрашивает MAX и после запуска покажет кнопку «…в MAX» на странице заказа. Документация: dev.max.ru.

### Перенос доставки с извинением

Не успеваешь (задержался на закупке)? В списке доставок нажми **«⏰ Перенести доставки»** (или «⏰ Перенести с извинением» у одного заказа):
1. отметь, кого переносим;
2. какие варианты предложить: «сегодня вечером 18:00–21:00», «завтра, тот же рейс», «завтра днём / вечером», «послезавтра»;
3. подарок за неудобство: **5 кг моркови / свёклы / лука** (или «на выбор клиента») либо без подарка;
4. «📤 Отправить».

Клиенту приходит извинение и ссылка `/r/<код>`: он выбирает время (и подарок, если на выбор). Заказ сам переезжает, подарок добавляется в заказ по цене 0 (в прибыли учитывается его закупка), тебе приходит «✅ Марина выбрала: завтра днём».
- Подписан в Telegram/MAX — сообщение уходит само (в Telegram с кнопкой «🕑 Выбрать время»), SMS — если подключён sms.ru.
- Не подписан — бот присылает тебе кнопку **💬 WhatsApp** с готовым текстом извинения и ссылкой.
- Пока клиент не ответил, заказ стоит на **первом** варианте. Через `RESCHEDULE_REMIND_MIN` (по умолчанию 2 часа) бот напомнит, кто не ответил, — позвони и нажми вариант за клиента.

**Клиент может перенести сам:** в сообщениях о заказе есть «Неудобно время? Перенести: ссылка». Тебе придёт «🔄 Клиент сам перенёс доставку: было … → стало …».

**Вечерний рейс** (`EVENING_START`–`EVENING_END`, по умолчанию 18:00–21:00) считается отдельным маршрутом со своим выездом и ссылкой на карту. Рейс заказа можно поменять в приложении (поле «Рейс»).

### Маршрут и время доставки

- Перед списком доставок (утром, вечером и по кнопкам «📋 Сегодня» / «📅 Завтра») бот сам строит **маршрут**: в каком порядке объезжать адреса, чтобы ездить меньше.
- У каждого заказа — **точка по порядку** («Точка 2 из 5») и **примерное окно прибытия** «🕑 13:45–14:45». Его можно называть клиенту.
- В шапке списка: время выезда, сколько примерно километров и часов, ссылка **«Открыть маршрут в Яндекс Картах»** со всеми точками по порядку и кнопка **«🔄 Пересчитать маршрут»** (например, после новых заказов).
- В приложении во вкладке «Заказы» — карточка «🧭 Маршрут» с теми же данными; заказы стоят в порядке объезда.
- Адреса ищутся на карте OpenStreetMap (бесплатно, 1 запрос в секунду; найденные координаты запоминаются у клиента). Если адрес не нашёлся, заказ ставится в конец без времени с пометкой «адрес не найден на карте — проверь»: поправь адрес клиента (улица и дом).
- ⚠️ **Время примерное**: бесплатные карты не знают о пробках, поэтому время в пути умножается на `TRAFFIC_FACTOR`. Если карта маршрутов недоступна, расстояние считается по прямой.

Настройки в `.env`:

| Переменная | Что значит |
|---|---|
| `CITY` | город, подставляется к адресам (например `Екатеринбург`) |
| `DEPOT_ADDRESS` | откуда выезжаешь (улица, дом). Пусто — маршрут начинается с первой точки |
| `ROUTE_START` | во сколько выезд, по умолчанию `10:00` |
| `SERVICE_MIN` | минут на одну точку (донести мешки, рассчитаться), по умолчанию `10` |
| `ETA_WINDOW_MIN` | ширина окна для клиента в минутах, по умолчанию `60` |
| `TRAFFIC_FACTOR` | поправка на пробки, по умолчанию `1.3` (в час пик можно `1.5`) |

После изменения `.env`: `docker compose up -d`.

### Как считается прибыль

```
Прибыль = выручка − закупочная цена проданного − 50 ₽ другу за каждую его заявку − расходы (газ, прочее)
```

- Закупочная цена берётся из вкладки «Цены» (картошка 20 ₽/кг, лук 20, морковь 27, свёкла 22).
- Закупку партии товара можно записать («купил картошки на 20 000»). Она видна отдельно и в прибыль второй раз не вычитается.
- Заявки, которые создаёт друг, автоматически помечаются «через друга» (−50 ₽). Отметку можно снять в заказе.

## Запуск (один раз, примерно 20 минут)

### 1. Создать бота
1. В Telegram открой **@BotFather** → `/newbot`.
2. Придумай имя (например «Картошка Артура») и username, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `123456:ABC...`. Сохрани его.

### 2. Ключ для распознавания голоса
1. Зарегистрируйся на **proxyapi.ru** (оплата в рублях).
2. Пополни баланс на 200–300 ₽. Этого хватит надолго: голосовое стоит копейки.
3. В личном кабинете создай **API-ключ** и сохрани его.

> Без ключа бот и приложение работают, только голосовые и скриншоты не распознаются. Заказы тогда добавляются через приложение.

### 3. Облако Amvera (проще всего, без команд, ~300 ₽/мес)
С российских серверов Telegram-боты часто не могут подключиться к Telegram: с 2026 года его блокируют. Amvera сама отправляет запросы к Telegram через зарубежный IP, а база остаётся в России.

1. Зарегистрируйся на **amvera.ru** по номеру телефона и пополни баланс.
2. **Создать проект → Приложение**: регион Москва, тариф «Начальный».
3. Код: вкладка **Репозиторий → GitHub**, выбери этот репозиторий и ветку `main`. Настройки сборки берутся из `amvera.yml`.
4. Вкладка **Домены**: добавь бесплатный домен и скопируй адрес.
5. Вкладка **Переменные**:
   - `BOT_TOKEN` — токен бота (как секрет);
   - `WEBAPP_URL` — адрес из шага 4, начинается с `https://`;
   - `AI_API_KEY` — ключ ИИ, можно добавить позже. Модели выбираются сами при запуске.
6. Нажми **Собрать** или **Перезапустить**. База хранится в папке `/data` и не пропадает при обновлениях.

### 3б. Свой сервер (VPS)
1. Купи самый дешёвый VPS с **Ubuntu 24.04** (1 CPU, 1 ГБ RAM). Лучше за границей: из России Telegram API часто недоступен.
2. Запиши **IP-адрес** и **пароль root**.
3. Подключись к серверу:
   - с Android через приложение **Termux**: `ssh root@IP`;
   - или через **JuiceSSH**.
4. Выполни команды:
   ```bash
   git clone https://github.com/makarovartur2008-cloud/gh-auth-login.git kartoshka
   cd kartoshka
   bash deploy.sh
   ```
5. Скрипт спросит токен бота и ключ ИИ, потом сам всё установит. Домен и https настраиваются автоматически через `ВАШ-IP.sslip.io`, покупать домен не нужно.

### 4. Начать работу
1. Открой своего бота и нажми **Start**. **Первый, кто нажал, становится владельцем.** Поэтому нажми сам, сразу после запуска.
2. Команда `/invite` даёт одноразовую ссылку для друга.
3. Открой **📱 Приложение → Цены** и проставь цены продажи лука, моркови, свёклы и закупку мёда.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | подсказка и кнопки |
| `/invite` | ссылка-приглашение для друга (только владелец) |
| `/users` | кто имеет доступ |
| `/remove ID` | убрать доступ |
| `/backup` | прислать копию базы сейчас (сам бот присылает её каждый вечер в 22:30) |

## Обслуживание

- **Ключ ИИ можно добавить позже** (или поменять сервис): `bash set_ai_key.sh` — спросит ключ, сам выберет доступные модели для текста и голоса и перезапустит бота. Подходит любой OpenAI-совместимый сервис с оплатой в рублях (ProxyAPI, AITUNNEL и т. п.). Если сайт сервиса не открывается — выключи VPN.

- **Обновить** после новых изменений: `cd kartoshka && git pull && docker compose up -d --build`
- **Резервная копия базы**: `bash backup.sh` (хранятся последние 30 копий). Чтобы делать копию автоматически каждую ночь:
  `(crontab -l; echo "0 3 * * * cd /root/kartoshka && bash backup.sh") | crontab -`
- **Логи**: `docker compose logs -f app`
- Все данные лежат в одном файле: `data/app.db`.
- **Восстановить из копии** (файл, который бот присылает каждый вечер): на Amvera — вкладка «Данные», загрузить файл вместо `app.db` и перезапустить; на своём сервере — положить файл в `data/app.db` и `docker compose restart app`.

## Для разработки

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest
DEV_USER_TG_ID=1 uvicorn app.main:app --reload   # приложение без Telegram (нужен пользователь с tg_id=1 в базе)
```

Устройство проекта:
- `app/bot.py`: Telegram-бот (aiogram);
- `app/notify.py`, `app/client_bot.py`, `app/max_bot.py`: сообщения клиентам (Telegram, MAX, SMS, WhatsApp-кнопка);
- `app/api.py`: API для приложения (FastAPI);
- `app/ai.py`: распознавание голоса и разбор фраз;
- `app/services.py`: логика заказов, постоянных клиентов и прибыли;
- `app/routing.py`: маршрут и примерное время доставки;
- `app/db.py`: база SQLite;
- `app/static/`: интерфейс приложения.
